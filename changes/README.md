# Heiward's changes waiting to be released

Each piece of work writes its changelog entry here, in a file named for its branch (`claude/some-work` writes `claude-some-work.md`), and leaves the version files and CHANGELOG.md alone. The entry has a bold line, What's new and/or What changed, and Before you update, without its `## ` heading. The next release sets the version, moves each entry into CHANGELOG.md and deletes its file, so two pieces of work never meet in the same lines.
