**Heiward in the Microsoft Store keeps up with new versions by itself, and its Store page says what's new in each.**

### What changed

- Heiward from the Microsoft Store gets each new version once Microsoft has checked it. When several versions come out while one is being checked, the newest follows once that one is in the Store, so none is skipped for long.
- The Store page's **What's new in this version** lists, in plain words, what changed since the Store's last version, newest first.

### Before you update

- Nothing: it updates itself as usual.
