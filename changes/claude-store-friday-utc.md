**Heiward from the Microsoft Store gets its weekly version even when GitHub skips a run.**

### What changed

- The weekly version for the Microsoft Store is sent on Fridays at 10:00 New York time, as before. On 13 November GitHub never started that run, so the week's version waited for someone to send it by hand.
- Friday's run now has two more chances later the same day. Once one of them has sent the version, the later ones see it on its way to the Store and send nothing again.

### Before you update

- Nothing: it updates itself as usual.
